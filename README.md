# bookjournal

A phone-first **learning journal**. Each day you note what you learned from a book, article, podcast, video, course or conversation: the key ideas in your own words, a line worth keeping, what you'll try, and what it connects to. Your ideas come back on a spaced schedule so you keep them, and a weekly review pulls the week together.

Every entry is a Markdown file saved to **your own private GitHub repo**. This repo holds only the app code, which is public and contains no entries or secrets.

**Status: Phase 1, planning.** Read [PLAN.md](PLAN.md) and open the clickable wireframes in [`prototypes/`](prototypes/index.html). The app itself is built in Phase 2, after a direction is chosen.

Built on the same approach as [myjournal](https://github.com/infinitepal178/myjournal).
